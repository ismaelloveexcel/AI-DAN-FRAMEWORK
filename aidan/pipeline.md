# AIDAN Pipeline — The 6-Step Business Pipeline

Every product follows exactly this pipeline. No shortcuts. No skipping steps.

---

## Step 1: Idea (Scout)

**What happens:** AIDAN generates or filters product ideas.

**Criteria:**
- Solves a real problem people already know they have
- Searchable (people are already looking for a solution)
- Fits the Mauritius or remote-global market

**Output:** One-line idea brief:
```
[Product Name]: [One sentence describing what it does and who it's for]
```

**Time allowed:** 1 session (max 2 hours)

---

## Step 2: Validation (Atlas)

**What happens:** Test the idea before writing a single line of code.

**Checklist (all must be YES):**
- [ ] People are searching for this (Google Trends, Reddit, TikTok)
- [ ] People are paying for something similar
- [ ] Can be built in 3 days or less
- [ ] Has recurring revenue potential (not just one-time)
- [ ] Fits the target market

**Output:** Validation verdict: PROCEED or KILL

**Rule:** If any box is unchecked → KILL the idea. Move to next idea.

**Time allowed:** 1 session (max 2 hours, no build work)

---

## Step 3: Build (Forge via Cursor)

**What happens:** Build the MVP using Cursor AI.

**Scope rules:**
- One core feature only
- Mobile-friendly UI
- Payment-ready (Stripe placeholder minimum)
- No nice-to-haves until first paying customer

**Cursor Prompt Template:**
```
Build MVP for: [product name]

Core feature: [one sentence]
User: [who uses it and how]
UI: Simple, glassmorphism style, mobile-friendly
Payment: Stripe checkout placeholder
Stack: [HTML/CSS/JS static OR Next.js OR Python FastAPI]
Timeline: 3 days max
```

**Output:** Deployable MVP (even if rough)

**Time allowed:** 3 days maximum. If it takes longer, the scope is wrong.

---

## Step 4: Launch

**What happens:** Put it live and tell people.

**Minimum to launch:**
- [ ] Landing page live (Vercel)
- [ ] Payment method ready (Stripe or manual)
- [ ] One launch post written and approved

**Launch channels:**
1. Reddit (r/mauritius, relevant subreddits)
2. LinkedIn (professional framing)
3. Facebook Groups (Mauritius job/business groups)
4. TikTok (if time allows — video format)

**Rule:** AIDAN must approve all public posts before publishing.

**Output:** Live product URL + first launch post published

**Time allowed:** 1 day

---

## Step 5: Revenue Tracking (Airtable)

**What happens:** Track every rupee, every user, every conversion.

**Airtable fields to update weekly:**
- Revenue_MRR (Rs and $)
- Users (total signups)
- Paying_Users
- Week
- Notes (what's working, what's not)

**Review cadence:** Every Sunday, 30 minutes.

**Target:** Rs 25,000/month ($500 MRR equivalent)

**Rule:** If MRR is flat for 2 weeks → run a weekly review with AIDAN. Something needs to change.

---

## Step 6: Weekly Improvement (Sage)

**What happens:** Review what worked and what didn't. Make ONE change.

**Weekly review format:**
```
✅ What worked this week
❌ What failed this week
🔧 ONE change for next week (not a list — one change)
```

**Rule:** Only ONE improvement per week. More than one = losing focus.

**Output:** Next week's single improvement committed to Airtable notes.

---

## The Non-Negotiable Rule

> **Do NOT start a new product until the current one hits $500 MRR.**

This pipeline repeats for each product — but only one at a time.
